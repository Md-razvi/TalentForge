# Project TalentForge
### AI-Powered Recruitment & Interview Management Platform
TalentForge is a Spring Boot based backend application that streamlines the recruitment process by combining traditional hiring workflows with AI-powered interview generation and evaluation.
The platform enables recruiters to create interview sessions, candidates to participate in interviews, and AI to generate relevant technical questions based on role, experience level, and difficulty. 

## Features
### Authentication & Security
- JWT Authentication
- User Registration & Login
- Role-Based Authorization
- Secure REST APIs
- Password Encryption using BCrypt
  ### AI Interview Module
- AI-generated interview questions
- Questions generated using Google Gemini API
- Questions based on:
  - Job Role
  - Experience Level
  - Difficulty
- Automatic fallback questions if AI is unavailable
